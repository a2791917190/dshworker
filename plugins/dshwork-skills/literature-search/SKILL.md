# 文献检索

## 何时用

用户想做**资料调研**:给定一个主题,要找来源、读要点、整理成带引用的综述或资料清单。

## 步骤

1. **界定问题**:把主题拆成可检索的关键词(中英文都列);明确时间范围、学科范围。
2. **多源检索**:用可用的搜索/抓取工具,从多个来源找材料;优先权威/一手来源。
3. **筛选**:按「相关性 + 可信度 + 时效」筛掉噪音,保留 5~15 条核心来源。
4. **归纳**:逐条提炼「它说了什么、支持什么结论」;相同的合并,冲突的并列。
5. **产出**:给出一份**带来源链接**的资料清单 + 要点综述;必要时点出研究空白。

## 产出要求

- 每条来源必须带**可点击链接**与标题。
- 区分「来源原话」与「你的归纳」。
- 找不到证据时明确说「未找到」,不要用模糊表述冒充结论。

## 不要做

- 不编造标题、作者、链接。
- 不把二手转述当成一手事实。
