# 报告生成

## 何时用

用户要"出一份东西"——报告、调研、方案、汇报——而不是只想聊几句时,用本技能组织产出。

## 步骤

1. **对齐目标**:先确认「给谁看、要多长、重点是什么、有无已有材料」。缺信息就先问,别猜。
2. **整理材料**:把用户给的文件/链接/要点收集起来;缺少关键事实时明确标注「待补」,不编造数据。
3. **列提纲**:给出 3~6 个一级标题的提纲,先让用户确认结构,再动笔。
4. **分节撰写**:每节「结论先行」,再给依据;能用列表/表格就用,别写大段空话。
5. **收尾**:给出「核心结论 / 风险与不确定 / 下一步建议」。

## 产出要求

- 默认输出 **Markdown**(标题层级清晰),方便再导出成 Word/PDF。
- 涉及数据必须注明来源或标注为估计值。
- 长度按用户要求;没要求时控制在能读完的篇幅,宁精不长。

## 不要做

- 不编造引用、数据、人名。
- 不在未确认提纲前就写完整长文(容易返工)。
