macOS 安装说明

你会看到这个

“DSHwork.app” was not opened because it contains malware. This action did not harm your Mac.

方法 A · 用终端下载（推荐）

ZIP 版

curl -L -o ~/Downloads/DSHwork-mac.zip \
  https://dshwork.ai/dist/DSHwork-0.1.0-arm64-mac.zip

cd ~/Downloads && unzip -q DSHwork-mac.zip && open DSHwork.app

DMG 版

curl -L -o ~/Downloads/DSHwork.dmg \
  https://dshwork.ai/dist/DSHwork-0.1.0-arm64.dmg

hdiutil attach ~/Downloads/DSHwork.dmg
# 把 DSHwork 拖进「应用程序」，然后：
xattr -dr com.apple.quarantine /Applications/DSHwork.app

方法 B · 已经下载了 / 已被移进废纸篓

  1. 先还原
  2. 去掉隔离标记
xattr -dr com.apple.quarantine ~/Downloads/DSHwork.app

xattr -cr ~/Downloads/DSHwork.app
open ~/Downloads/DSHwork.app

方法 C · 不想开终端

  1. 还原
  2. 打开系统设置
  3. 找到提示
  4. 仍要打开
  5. 再次打开
